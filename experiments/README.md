# Experimentos

Cada experimento deve ser pequeno o suficiente para terminar em poucos dias e
completo o suficiente para outra pessoa reproduzir. Use
`templates/sdd-template.md` e mantenha o status explícito no arquivo.

Ordem recomendada:

1. Definir hipótese e alternativa manual.
2. Implementar o menor agente possível.
3. Executar o harness com casos positivos, ambíguos e adversariais.
4. Registrar evidências, custo e falhas.
5. Publicar a crônica somente depois da decisão de adoção.
