# Site público

Esta pasta é o artefato estático publicado pelo workflow em
`.github/workflows/pages.yml`. O site é servido sem build, usando `index.html` e
`styles.css`.

Cada crônica deve apontar para o SDD, o harness e as evidências correspondentes.
O conteúdo publicado não deve expor credenciais, dados de clientes ou prompts
que revelem informações confidenciais.
